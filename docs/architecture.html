任务执行流程

flowchart TD Start([用户提交任务]) --> Validate{验证任务} Validate -->|无效| Err[返回错误] Validate -->|有效| CreateTask[创建任务记录
状态: PENDING] CreateTask --> Cache[更新缓存] Cache --> Notify[WebSocket通知
任务创建] Notify --> Queue[加入Celery队列] Queue --> Worker[Worker拾取任务] Worker --> Assign[分配给合适Agent] Assign --> UpdateStatus[更新状态: PROCESSING] UpdateStatus --> Exec[执行LLM调用] Exec -->|成功| Complete[任务完成
状态: COMPLETED] Exec -->|失败| Fail[任务失败
状态: FAILED] Complete --> Store[存储结果] Fail --> Store Store --> Notify2[WebSocket通知
状态变更] Notify2 --> Done([用户获取结果])

🔌 API 端点

Agent API

GET /api/v1/agents - 获取Agent列表
GET /api/v1/agents/{id} - 获取Agent详情
POST /api/v1/agents - 创建Agent
PUT /api/v1/agents/{id} - 更新Agent
DELETE /api/v1/agents/{id} - 删除Agent

Task API

GET /api/v1/tasks - 获取任务列表
GET /api/v1/tasks/{id} - 获取任务详情
POST /api/v1/tasks - 创建任务
POST /api/v1/cluster/execute - 执行集群任务

Auth API

POST /api/v1/auth/login - 用户登录
POST /api/v1/auth/refresh - 刷新令牌
GET /api/v1/auth/me - 获取用户信息

健康检查 & 监控

GET /health - 基本健康检查
GET /liveness - Kubernetes存活探针
GET /readiness - Kubernetes就绪探针
GET /metrics - Prometheus指标
GET /info - 服务信息
